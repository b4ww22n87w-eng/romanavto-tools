# РоманАвто — инструменты

Программы для подборки автомобилей с пробегом (Ярославль, до 750 000 ₽).

## Что здесь лежит

| Файл | Что делает |
|---|---|
| `collect_drom.js` | Собирает объявления с Дрома в `drom_raw.json` |
| `collect_autoru.js` | Собирает объявления с Авто.ру в `autoru_raw.json` |
| `1_merge.py` | Объединяет оба сайта, убирает дубли, сохраняет `all_rows.json` |
| `2_make_table.py` | Считает медианы по аналогам и собирает таблицу `Подборка авто.xlsx` |

## Как запустить

Нужны Node.js с Playwright и Python 3 с openpyxl.

```bash
node collect_drom.js 60
node collect_autoru.js 60
python3 1_merge.py
python3 2_make_table.py
```

## Ограничения

- Авито не собирается: сайт блокирует запросы с серверов.
- Сайты ограничивают частоту запросов, поэтому между страницами стоят паузы.
- Оценка «дешевле аналогов» сравнивает цену с медианой той же модели ±2 года
  и не учитывает пробег и состояние машины.
- Город, цену и радиус поиска нужно менять в адресах внутри `collect_*.js`.
