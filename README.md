# РоманАвто — поиск автомобилей

Программа собирает объявления о продаже автомобилей с Дрома и Авто.ру,
объединяет их, убирает дубли и показывает, какие машины стоят дешевле аналогов.

Авито не собирается: сайт блокирует запросы с серверов и требует проверку «я не робот».

## Что делает

1. Собирает объявления с двух сайтов по адресам из `config.json`.
2. Находит машины, выложенные на обоих сайтах, и оставляет одну запись с двумя ссылками.
3. Для каждой машины считает медианную цену той же модели близких годов.
4. Строит таблицу Excel и данные для страницы с фильтрами.

## Файлы

| Файл | Назначение |
|---|---|
| `config.json` | Настройки: адреса поиска, критерии подборки |
| `search.py` | Главная программа |
| `collect_drom.js` | Сбор с Дрома |
| `collect_autoru.js` | Сбор с Авто.ру |
| `page.html` | Страница для телефона с фильтрами, читает `data.json` и `meta.json` |

## Запуск

Нужны Python 3 с `openpyxl` и Node.js с Playwright.

```bash
python3 search.py
```

Пересчитать по уже собранным данным, не обращаясь к сайтам:

```bash
python3 search.py --offline
```

Результат появляется в папке `out/`: `Подборка авто.xlsx`, `data.json`, `meta.json`.
Полный сбор занимает 15–25 минут: между страницами стоят паузы, чтобы сайты не блокировали запросы.

## Настройки

В `config.json`:

- `drom_url`, `autoru_url` — адреса поиска. Город, радиус и верхняя граница цены задаются в них.
- `max_pages` — сколько страниц выдачи читать на каждом сайте.
- `exclude_towns` — города, которые не нужны в результате.
- `selection` — критерии листа «Подборка» в таблице:
  - `price_min`, `price_max` — цена;
  - `year_from` — год выпуска от;
  - `km_max` — пробег до;
  - `min_discount` — насколько цена должна быть ниже медианы аналогов (0.12 = 12%);
  - `private_only` — только частники (`true` или `false`);
  - `transmissions` — коробки, например `["АКПП", "вариатор"]`; пустой список = любые;
  - `brands` — марки, например `["Лада", "Kia"]`; пустой список = любые.

## Ограничения

- «Дешевле аналогов» сравнивает только цену. Пробег и состояние машины не учитываются.
- Сравнение есть, только если в базе нашлось пять и больше аналогов.
- Отметки «битый» и «проблемы с документами» есть только у объявлений Дрома.
- Объявления не проверяются по базам. Часть может быть снята уже после сбора.
- Если сайт изменит вёрстку страниц, сбор с него перестанет работать и его придётся чинить.
